## ✨ Creative & Real-World Features

### 1. 🛠️ Interactive Real-World Problem Workstation (Hero Right Side)
A multi-tab interactive engineering console:
- **🎮 60 FPS Game Physics Simulator (Scratch / Canvas)**:
  - Demonstrates game loop timing, player gravity, obstacle avoidance, diamond collection, and AABB collision detection.
- **🗺️ Campus Route Optimizer (Dijkstra's Algorithm)**:
  - Interactive DY Patil campus graph network (Hostel, CS Lab, Cafeteria, Library, Sports Arena, Auditorium).
  - Calculates dynamic shortest paths and displays real-time congestion savings (38% transit reduction).
- **💸 FairShare Student Debt Simplifier**:
  - Solves the classic roommate expense tangle by reducing $O(N^2)$ transaction meshes down to at most $N-1$ transfers.
  - Interactive slider calculates gateway fee savings in real time.
- **⚡ Interactive CLI Terminal (`ajay@portfolio:~$`)**:
  - Fully working shell supporting commands: `solve`, `skills`, `projects`, `whoami`, `contact`, `help`, and `clear`.
