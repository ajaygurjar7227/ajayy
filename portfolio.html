CASE 01
Team Game Development • Scratch 3.0

Multi-Level 2D Arcade Adventure Game

🚨 The Real-World Problem

Distributed 5-person student team with no prior shared game engine experience faced severe collision lag, sprite desynchronization, and unpredictable game loop drops during peak action sequences.

⚙️ Engineering Solution

Decoupled rendering from collision math using discrete broadcast ticks. Created a centralized state machine for score persistence, audio cue orchestration, and level transitions. Established daily standups to unblock teammate sprites.

📈 Measurable Impact

Maintained stable 60 FPS gameplay across all 4 stages. Zero fatal crashes on final demo day, earning highest marks for team coordination and game architecture in Pune.

Graph Theory • C++ • Dijkstra's Algorithm

Campus Route & Congestion Optimizer

CASE 03
Greedy Algorithm • Financial Tooling

FairShare: Multi-Party Debt Minimizer

🚨 The Real-World Problem

College students sharing flats and hackathon groups in Pune/Jaipur end up with dozens of tangled micro-debts (groceries, WiFi, food orders), leading to payment confusion, awkward disputes, and multiple banking fee penalties.

⚙️ Engineering Solution

Engineered a greedy graph debt-cancellation algorithm that computes net balances for all parties and matches maximum creditors with maximum debtors, shrinking an $O(N^2)$ transaction mesh down to at most $N-1$ optimal transfers.

📈 Measurable Impact

Reduces bank transfers by an average of 65%. Generates instant settlement links, eliminating friendship friction over shared student expenses.
